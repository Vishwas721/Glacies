# Detour factor for routes added by scenarios

City `bengaluru`; current `[scenario] detour_factor` = 1.15.

Generated by `glacies scenario calibrate`. Consecutive stops of bus patterns, 200-2000 m apart in a straight line: 15,187 distinct pairs, 2,000 sampled (seed 2026), 1,997 with a walk path between them.

| Statistic | Walk distance / straight line |
|---|---|
| p10 | 1.01 |
| p25 | 1.02 |
| p50 | 1.06 |
| p75 | 1.17 |
| p90 | 1.34 |
| mean | 1.15 |

Walking distance ignores one-way streets and turn restrictions, so it understates a bus's road distance. The suggested `[scenario] detour_factor` is therefore the mean (**1.15**), not the median. The value in city.toml is still **Assumed**: it is a measured property of existing stop spacing, applied to routes that do not exist.
